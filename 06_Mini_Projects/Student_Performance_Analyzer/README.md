# 📊 Student Performance Analyzer

A Python and NumPy project that analyzes the academic performance of students across multiple subjects. The program collects marks for each student, calculates statistics, identifies the class topper, determines the best-performing subject, and generates grades based on the student's overall average.

---

## Features

- User enters the number of students.
- User enters marks for:
  - Mathematics
  - Science
  - English
- Stores data in a 2D NumPy array.
- Calculates:
  - Subject-wise average marks
  - Student-wise average marks
  - Class topper
  - Best-performing subject
- Generates grades (A+, A, B, C, D, F) based on average marks.
- Displays an organized performance report.
